# Toxic-comment data-quality report

Generated by `python -m scripts.prepare_toxicity` (seed 42). **This report contains no offensive comments, only counts.**

Dataset: Jigsaw Toxic Comment Classification Challenge, as redistributed on Hugging Face (`thesofakillers/jigsaw-toxic-comment-classification-challenge`). Comments come from Wikipedia talk pages (about 2017) and were labelled by human raters. Licence per the dataset card: CC0 for the labels, with the comment text under Wikipedia's CC BY-SA 3.0. Task: multi-label (one comment can carry several labels).

## 4. Official test set

The Hugging Face "test" split has 306,328 rows in **two stacked blocks** instead of one merged table: 153,164 rows with the comment text but no labels, and 153,164 rows with the labels but no text. Reading it naively yields either text without labels or labels without text. The blocks are joined by `id` (ids unique in each block: True / True), giving 153,164 rows. The competition marked rows it did not score with -1 in every label.

- Scored rows (labels not -1): **63,978**.
- After removing duplicates (38), conflicting rows (2) and comments that also appear in the training file (30): **63,908** kept.
- Treating -1 as a real label would corrupt every metric; only scored rows are used.

## 6. Known limitations

- Wikipedia talk-page comments from about 2017: slang, targets and platform style differ from today's social media.
- Labels come from crowd raters and contain disagreement and noise.
- Rare labels have few examples (`threat` 327 in the training split), so their scores are unstable.
- English only.
- The text is offensive. Read error-analysis files in small batches.
