## Intended use
Show what can and cannot be learned from the text of an address alone, with the features behind the score. The address is never opened.

**Out of scope:** Declaring a site safe; blocking sites; judging page content, certificates, domain age or reputation; shortened links (the app says 'Cannot judge').

## Training data
PhreshPhish (CC BY 4.0, 2024 to 2025) plus PhiUSIIL (legitimate homepages balance PhreshPhish's deep pages). Structural shortcuts found in the data (www, https, query string, empty path) were removed as features.

Sizes: train 596,183, val 114,650, test 162,718, compphish 12,148, phishbench 856, openphish_2026-10-12 286, challenge 68. Details: `docs/dataset_cards/`.

## Known limitations
- Reads only the URL text: no page content, certificate, domain age or reputation data.
- The query string and fragment are ignored.
- Shortened links cannot be judged without following them, which this project never does.
- Free-hosting platforms host both legitimate and phishing pages; the URL text alone often cannot separate them.
- Public datasets contain legitimate URLs mostly from popular sites; small unknown legitimate sites may look unusual.
- Trained on 2024-2025 data; phishing changes quickly.

## Ethical considerations
A false alarm can make a legitimate small site look dangerous. The model mistakes many legitimate pages on free hosting platforms for phishing because in the training data almost every address on those platforms was phishing. The app says 'Potentially phishing' or 'Likely legitimate', never 'safe'.
